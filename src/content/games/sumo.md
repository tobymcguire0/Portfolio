Sumo started as **Simply Sumo**, a straightforward fighting game published on itch.io. It has since evolved into a full multiplayer experience with online play, currently being polished for a Steam release.

The enhanced version focuses heavily on multiplayer networking, which was the primary learning goal behind the project. Building reliable real-time multiplayer from the ground up required tackling synchronization, latency management, lobby systems, and all the challenges that come with networked game state.

The original version is still playable on [itch.io as Simply Sumo](https://toblet.itch.io/simply-sumo).
