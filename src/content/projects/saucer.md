Saucer is a personal project aimed at learning full stack development fundamentals. The app allows users to organize, search, and manage recipes through a clean interface. It will allow multiple users to login from any device and quickly fetch all of their saved recipes no matter where they are.

Built with TypeScript across the stack, it covers frontend UI, backend API design, database management, user authentication, and deployment considerations. It represents the first in a planned series of projects focused on building deep full stack proficiency.
