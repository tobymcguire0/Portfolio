Saucer is a personal project aimed at learning full stack development fundamentals. The app allows users to organize, search, and manage recipes through a clean interface. A user can log in from anywhere on any device and synchronize their recipes. Recipes are uploaded via scraping a recipe's URL, or by uploading an image or text file which gets read by Claude Haiku and generated into a draft recipe.

Built with TypeScript across the stack, it covers frontend UI, backend API design, database management, user authentication, AI information gathering, and deployment considerations. It represents the first in a planned series of projects focused on building deep full stack proficiency.
