A shader development project focused on creating visual effects for game environments. Explores custom rendering techniques using Unity's shader pipeline, including vertex manipulation and fragment shading for stylized world visuals.

This project was ultimately used for a game project [Modulos](https://org.osu.edu/gamedev/games/modulos/). Unfortunately this game wasn't uploaded to github and the source is lost, but the executable still exists on the OSU Game Creation Club's website.
